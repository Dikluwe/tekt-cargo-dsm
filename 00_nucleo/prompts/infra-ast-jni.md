# Extração de chamadas JNI (L3)
Hash do Código: 213abea7

Analise somente os documentos Java informados, em memória, com o compilador
do JDK. Registre o identificador das chamadas e o método chamador.
Associe uma chamada resolvida ao método static native sem sobrecarga
nativa de mesmo nome quando a classe contém a carga literal de biblioteca.
Use a identidade da classe e o escape JNI para formar o nome de símbolo.
